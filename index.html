BM

BusinessMind AI

Intelligent Business Intelligence Platform — full-stack application (FastAPI + PostgreSQL + React). This repository is the deliverable; run it with Docker to launch the complete app: 

cp .env.example .env   # set JWT_SECRET & DB_PASSWORD
docker compose up --build
# → open http://localhost:8000

What's inside

  • AI data analysis — KPIs, trends, anomalies, correlations (pandas)
  • Natural-language assistant with optional Ollama LLM narration
  • ML forecasting (scikit-learn) with 95% prediction intervals
  • Automated PDF business reports
  • JWT auth, RBAC, strict multi-tenant isolation
  • 34 automated tests incl. security & tenant-isolation suites
